\subsection{Reproduire et interpréter les incertitudes}
Compiler utilise seulement les sources et figures locales. Recalculer le
renouvellement exige les instantanés des deux runs identifiés ci-dessus et
le script \chemin{../scripts/renewal_stage.py}. Les calculs transférés de
l'article proviennent de ses scripts \code{revision\_article.py},
\code{figures\_v2.py} et \code{ages\_v2.py}, conservés dans le dossier
frère ; ils n'ont pas été réexécutés pour modifier ses résultats.
Les générateurs partagés historiques ne doivent pas être utilisés pour
écraser cette version révisée du rapport.

Les IC95 de Student reposent sur les graines, et non sur une indépendance
supposée des entités ou des pas. Le bootstrap des courbes de distribution
rééchantillonne des runs entiers. Les anciennes images conservent leurs
conventions : dispersion, erreur binomiale conditionnelle, erreur-type ou IC.
Un contrôle autonome de compilation ne valide pas toutes les simulations
et ne constitue pas une installation propre testée sur une autre machine.
