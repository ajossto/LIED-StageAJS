## Reconstruction

Pour une simple compilation, deux passes pdflatex dans le dossier `latex/` suffisent normalement. Consulter `../revision_documents/README.md` pour recalculer les compléments et synchroniser les sources. Les données de campagne et Simulation Lab sont présentes sur ce poste mais pas toutes versionnées ; une compilation autonome n'est pas une reproduction scientifique depuis un clonage neuf.
