# Étude de sensibilité M4B

Ce dossier contient la campagne reproductible de sensibilité de M4B.

## Navigation

- `report/rapport_final.pdf` : rapport scientifique final.
- `JOURNAL.md` : journal d'exécution et décisions.
- `scripts/` : construction des plans, exécution et analyses.
- `manifests/` : plans expérimentaux.
- `figures/` : figures produites pour les rapports.
- `results/` : résultats bruts et métriques dérivées ; dossier volumineux.
- `prompts/m4b/` : prompt M4B effectivement associé à cette campagne.
- `prompts/m4_m4b/` : version antérieure couvrant conjointement M4 et M4B.
- `inputs/selection_graphiques_m4/` : feuilles de sélection graphique ayant
  servi de matériau d'entrée.

Les prompts et entrées sont conservés ici pour assurer la provenance de
l'étude ; ils ne doivent pas être confondus avec le futur prompt M4.2.
